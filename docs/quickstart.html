quickstart

Your first chart in five minutes.

The chart comes from your notes, so start there. You need Obsidian 1.13 or later with the core Bases plugin turned on.

step 0 · install

Install Agate

Agate isn't in the community directory yet, so install it one of two ways.

recommended

With BRAT

Install the BRAT plugin, then Add beta plugin and enter Casyfill/Agate. BRAT keeps it updated as new releases ship.

manual

From a release

Download main.js, manifest.json and styles.css from the latest release into .obsidian/plugins/agate/, then enable Agate in Community plugins.

the three steps

From notes to a chart.

1

Have a base of notes

Any folder of notes with properties works: a reading log, trips, projects, a journal. Make a base over them and tidy the columns with the Bases toolbar.

The properties you see are exactly the fields your chart can draw.

2

Make the chart

Add a view with the Agate chart layout, then Pick a recipe and map a property to each axis.

Or hit Copy prompt for an LLM, describe the chart you want in plain words, and paste the returned spec into the view.

3

Put it in a note

Embed the base view wherever you write:

![[Books.base#Ratings]]

Or point an Agate block at a spec file and a base:

```agate
spec: charts/ratings.vl.json
base: Library/Books.base
```

good to know

reuse

One spec, many views

The same spec file backs a filtered view, a grouped view and an embed in a daily note. Drop it in a note template and every new note gets the chart.

per-chart

Options live in the view

Theme, renderer (SVG or canvas), interactivity and the export menu are set per chart in the base view options, or as envelope keys in an Agate block — over the vault-wide defaults in Settings → Agate.

your look

Themes follow your vault

The dynamic obsidian theme reads your Obsidian fonts and colours and redraws on light/dark switch. For a fixed look, set a theme per chart, or paste a Copy theme prompt result into the Theme file setting.

external data

Per-note data, if you need it

A note can point at a CSV or URL (or a FRED id); Agate loads one dataset per row so each note draws its own series. Remote fetching is off until you turn on Load remote data.

play with it

Try the demo vault

Everything on this site ships in the repo as a made-up personal vault. Open it, change a note and watch the charts follow.

git clone https://github.com/Casyfill/Agate.git && cd Agate
npm install && make demo extras   # build, link the plugin, fetch the themes
# then open the demo-vault folder as a vault in Obsidian
