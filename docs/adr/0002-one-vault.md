# ADR-0002: One repo vault for showcase and tests

| | |
|---|---|
| Status | Accepted (2026-10-12) |
| Date | 2026-10-12 |
| Deciders | Philipp (maintainer) |
| Supersedes | The `test-vault/` parts of ADR-0001 D1, D2 and D8 (layer 3 setup); the rest of ADR-0001 stands |

## Context

The repo had two vaults. `test-vault/` (ADR-0001 D1, D8) held fixtures for every surface, broken specs on purpose and the manual checklist. `demo-vault/` (added 2026-10-07) held a made-up personal vault for screenshots. They had grown into each other: the demo generator copied its world map out of `test-vault/geo/`, both had a travel globe, a sunburst and a mood beeswarm, and the screenshots for the site (goals R2) would have come from charts that the render tests only partly covered.

## Decision

D1. **One vault, `demo-vault/`, with two halves.** Everything outside `tests/` is the showcase: the polished area notes, generated by `scripts/demo-vault.mjs`. `tests/` is the former test vault, unchanged in purpose: `tests/Surfaces/` (one note per surface), `tests/charts/`, fixture notes, `tests/M0 Checklist.md`, and `tests/Test guide.md` (formerly `Start here.md`). The vault's `Start here.md` says which half is which.

D2. **The halves don't see each other's notes.** Test bases filter on `file.inFolder("tests/…")`; showcase bases filter on `type`, which test notes don't set. Test notes whose names clash with showcase notes (12 places, 13 books) carry a ` (test)` suffix, so every `[[link]]` in the vault resolves to exactly one note, whatever Obsidian's tie-break for duplicate names.

D3. **Every chart in the vault is rendered by the test suite.** `test/render/specs.test.ts` covers `tests/charts/`, `test/render/demo-vault.test.ts` covers `charts/`. A screenshot is always of a spec the suite renders.

D4. **One install target.** `npm run install:local` links the build into `demo-vault/` by default; `AGATE_VAULT` still points it elsewhere.

## Consequences

- Opening the repo vault shows the showcase first; developers go to `tests/Test guide.md`. The vault's sunburst and graph views include `tests/` notes unless a base scopes them out (the showcase `Vault` base does: `notes/` only).
- `scripts/demo-vault.mjs` deletes and rewrites `notes/`, `attachments/`, `bases/` and `.obsidian/types.json`; it never touches `tests/`.
- Paths in old commits, issues and ADR-0001 still say `test-vault/`; read them as `demo-vault/tests/`.
