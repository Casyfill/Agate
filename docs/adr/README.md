# Architecture decision records

One file per decision, numbered `NNNN-short-title.md`. Status moves through Proposed → Accepted → (Superseded by ADR-XXXX | Deprecated). An accepted ADR is not edited for substance; a new ADR supersedes it and both link to each other.

Sections: Status table, Context, Decision (numbered D1…Dn so later ADRs can reference a single point), Roadmap where relevant, Consequences, Open questions, References.
